# AINVM 规范(v0)

## 1. 设计目标
- **确定性执行**: 同样的输入在所有节点上得到同样的结果
- **可计费**: 每条指令有确定 gas 成本, 防止死循环和资源滥用
- **简单但可扩展**: 先实现最小指令集, 后续再扩展
- **适合作为"代码挖矿(PoC)"和简单治理逻辑的执行环境**

## 2. 执行模型
- **栈机模型**(stack-based VM)
- **组件**: 
  - 程序count器(PC): 跟踪当前执行的指令位置
  - 栈(Stack): 用于临时数据存储和计算
  - 简单内存/存储(Memory): 用于持久化数据
  - gas count器(GasUsed, GasLimit): 跟踪执行成本
- **执行过程**: 
  - 从 PC=0 开始按字节码顺序执行
  - 每执行一条指令, 消耗对应的 gas
  - 当遇到 HALT / RETURN 或 gas 用完时停止执行

## 3. 最小指令集(v0)

| 指令 | 操作码 | 描述 | 操作数 | 栈影响 | Gas 成本 |
|------|--------|------|--------|--------|----------|
| PUSH | 0x01 | 将常量压入栈 | 1字节常量 | 栈顶 +1 | 1 |
| POP | 0x02 | 弹出栈顶元素 | 无 | 栈顶 -1 | 1 |
| ADD | 0x03 | 栈顶两元素相加 | 无 | 栈顶 -1 | 2 |
| SUB | 0x04 | 栈顶两元素相减 | 无 | 栈顶 -1 | 2 |
| MUL | 0x05 | 栈顶两元素相乘 | 无 | 栈顶 -1 | 3 |
| DIV | 0x06 | 栈顶两元素相除 | 无 | 栈顶 -1 | 3 |
| LOAD | 0x07 | 从内存加载值到栈 | 1字节地址 | 栈顶 +1 | 2 |
| STORE | 0x08 | 将栈顶值存入内存 | 1字节地址 | 栈顶 -1 | 2 |
| JMP | 0x09 | 无条件跳转 | 1字节偏移 | 无 | 1 |
| JZ | 0x0A | 若栈顶为0则跳转 | 1字节偏移 | 栈顶 -1 | 2 |
| HALT | 0x0B | 终止执行 | 无 | 无 | 0 |
| RETURN | 0x0C | 终止执行并返回栈顶值 | 无 | 无 | 0 |

### 指令详细说明

#### PUSH <value>
- **操作码**: 0x01
- **操作数**: 1字节常量(0-255)
- **栈影响**: 将常量压入栈, 栈顶指针+1
- **Gas 成本**: 1

#### POP
- **操作码**: 0x02
- **操作数**: 无
- **栈影响**: 弹出栈顶元素, 栈顶指针-1
- **Gas 成本**: 1

#### ADD
- **操作码**: 0x03
- **操作数**: 无
- **栈影响**: 弹出栈顶两个元素, 将它们的和压入栈, 栈顶指针-1
- **Gas 成本**: 2

#### SUB
- **操作码**: 0x04
- **操作数**: 无
- **栈影响**: 弹出栈顶两个元素, 将第二个元素减去第一个元素的结果压入栈, 栈顶指针-1
- **Gas 成本**: 2

#### MUL
- **操作码**: 0x05
- **操作数**: 无
- **栈影响**: 弹出栈顶两个元素, 将它们的乘积压入栈, 栈顶指针-1
- **Gas 成本**: 3

#### DIV
- **操作码**: 0x06
- **操作数**: 无
- **栈影响**: 弹出栈顶两个元素, 将第二个元素除以第一个元素的结果(整数除法)压入栈, 栈顶指针-1
- **Gas 成本**: 3

#### LOAD <addr>
- **操作码**: 0x07
- **操作数**: 1字节地址(0-255)
- **栈影响**: 从指定内存地址加载值并压入栈, 栈顶指针+1
- **Gas 成本**: 2

#### STORE <addr>
- **操作码**: 0x08
- **操作数**: 1字节地址(0-255)
- **栈影响**: 弹出栈顶元素并存储到指定内存地址, 栈顶指针-1
- **Gas 成本**: 2

#### JMP <offset>
- **操作码**: 0x09
- **操作数**: 1字节偏移(0-255)
- **栈影响**: 无
- **Gas 成本**: 1

#### JZ <offset>
- **操作码**: 0x0A
- **操作数**: 1字节偏移(0-255)
- **栈影响**: 弹出栈顶元素, 若为0则跳转, 栈顶指针-1
- **Gas 成本**: 2

#### HALT
- **操作码**: 0x0B
- **操作数**: 无
- **栈影响**: 无
- **Gas 成本**: 0

#### RETURN
- **操作码**: 0x0C
- **操作数**: 无
- **栈影响**: 无
- **Gas 成本**: 0

## 4. 字节码格式
- **程序表示**: 一个字节数组(Uint8Array)
- **约定**: 
  - 第一字节为 opcode
  - 部分指令后跟操作数(如常量, 地址, 偏移)
- **简化处理**: 
  - 所有常量, 地址, 偏移均为1字节(0-255)
  - 程序最大长度为256字节

## 5. Gas 模型
- **每条指令一个固定 gas 成本**(见指令集表)
- **执行入口参数**: 
  - `gasLimit`: 执行的最大 gas 消耗
- **执行过程**: 
  - 累计 `gasUsed`
  - 当 `gasUsed > gasLimit` 时, 立即终止并返回 "out of gas" 状态

## 6. 与区块链的关系(设计草案)
- **AINVM 程序未来将以"合约"形式挂在链上**: 
  - 交易中包含待执行的程序 ID 或字节码
  - 节点在应用交易时执行该程序, 修改状态
- **本轮仅实现 VM 内核和本地执行**, 不真正上链

## 7. test用例

### test用例 1: 简单算术
```
字节码: [0x01, 0x05, 0x01, 0x03, 0x03, 0x0B]  // PUSH 5, PUSH 3, ADD, HALT
预期结果: 栈顶为 8
Gas 消耗: 1+1+2=4
```

### test用例 2: 条件跳转
```
字节码: [0x01, 0x00, 0x0A, 0x05, 0x01, 0x01, 0x0B, 0x01, 0x00, 0x0B]  // PUSH 0, JZ 5, PUSH 1, HALT, PUSH 0, HALT
预期结果: 栈顶为 0
Gas 消耗: 1+2+1+0=4
```

### test用例 3: 内存操作
```
字节码: [0x01, 0x42, 0x08, 0x00, 0x07, 0x00, 0x0B]  // PUSH 66, STORE 0, LOAD 0, HALT
预期结果: 栈顶为 66
Gas 消耗: 1+2+2+0=5
```

## 8. 实现计划
1. **实现 VM 内核**: 
   - 栈机核心逻辑
   - 指令执行引擎
   - Gas 计费机制

2. **实现字节码编译器**(可选): 
   - 简单汇编语言到字节码的转换

3. **编写test套件**: 
   - 指令级test
   - 程序级test
   - Gas 计费test

4. **与区块链集成**(v0): 
   - AINVM 程序将以"合约"形式挂在链上
   - 支持 CONTRACT_DEPLOY 和 CONTRACT_CALL 交易类型
   - 节点在应用交易时执行该程序, 修改合约存储状态

## 8. 合约存储模型

### 8.1 存储结构
- **每个合约有一个独立的 storage**: 内部是一个 key → value(整数)的映射
- **存储访问**: AINVM via LOAD/STORE 指令访问内存, 内存地址对应存储的键
- **存储同步**: AINVM 执行结束后, memory 中的数据会同步到合约的 storage

### 8.2 访问限制(v0)
- **不支持访问账户余额**: VM 无法直接读取或修改任何账户的余额
- **不支持网络 IO**: VM 无法进行任何网络call或外部世界交互
- **不支持外部合约call**: VM 只能操作合约自己的存储
- **治理状态隔离**: 不允许直接读写治理状态(governanceState), 合约存储仅限于 contracts[contract_id].storage
- **未来扩展**: 即使后续扩展, 也必须via受控接口(例如只能读取只读视图, 写入需要额外治理授权)

### 8.3 错误处理与 Gas 限制
- **错误处理**: 当发生以下错误时: 
  - 栈下溢
  - 除零错误
  - Gas 用完
  - contract_id does not exist
- **处理方式**: 
  - 不更新合约存储
  - 不影响本区块中其他交易的执行
  - 在日志中有明确的错误记录
- **Gas 限制**: 每个 CONTRACT_CALL 交易必须指定 gas_limit, 执行时严格检查, 超出即终止执行

### 8.4 实现约定
- **内存地址**: using 1 字节地址(0-255)作为存储键
- **存储值**: using整数类型存储值
- **初始状态**: 新部署的合约 storage 为空
- **execution result**: 执行complete后, memory 中的所有数据都会写回 storage
