# NexusGenesis 完善行动计划

> 基于战略讨论确定的内容，制定详细执行计划
> 创建日期: 2026-06-29
> 目标: 一个月内实现网络稳定、技术无大问题、接入顺畅、初步达到项目设定场景

---

## 第一阶段: 稳定与清理(第1周, 6月30日-7月6日)

### 目标: 确保网络稳定运行，清理历史遗留问题

### 任务1.1: 启用PoW防刷机制
- **优先级**: P0
- **预估工时**: 2小时
- **具体步骤**:
  1. SSH登录服务器，设置环境变量 `POW_REQUIRED=true`
  2. 重启genesis节点
  3. 验证注册API要求PoW挑战
  4. 测试: 尝试无PoW注册应被拒绝
- **验收标准**: 新AGENT注册必须完成PoW挑战
- **风险**: 难度4前导零可能过低，需观察后调整

### 任务1.2: 清理僵尸AGENT
- **优先级**: P0
- **预估工时**: 3小时
- **具体步骤**:
  1. 查询所有sim-agent列表
  2. 保留5个用于压力测试
  3. 清理其余95个僵尸AGENT
  4. 更新AGENT注册表
  5. 验证AGENT数量降至30左右
- **验收标准**: AGENT数量从125降至约30(25真实+5测试)

### 任务1.3: 修复数据一致性Bug
- **优先级**: P1
- **预估工时**: 4小时
- **具体步骤**:
  1. 定位totalNGENAwarded统计逻辑
  2. 修复mint操作的追踪
  3. 重新计算累计奖励
  4. 验证API返回正确数据
- **验收标准**: totalNGENAwarded与实际发放量一致

### 任务1.4: 建立监控告警
- **优先级**: P1
- **预估工时**: 4小时
- **具体步骤**:
  1. 安装基础监控脚本(CPU/内存/磁盘)
  2. 设置节点健康检查
  3. 配置简单告警(邮件或webhook)
  4. 验证告警触发
- **验收标准**: 节点异常时能及时告警

### 任务1.5: 完善自动备份
- **优先级**: P1
- **预估工时**: 2小时
- **具体步骤**:
  1. 编写定时备份脚本(每6小时)
  2. 备份到本地+异地
  3. 验证备份可恢复
- **验收标准**: 备份自动执行且可验证恢复

## 第二阶段: 接入与生态(第2周, 7月7日-7月13日)

### 目标: 实现一键接入，开放任务生态

### 任务2.1: 完善一键部署脚本
- **优先级**: P0
- **预估工时**: 6小时
- **具体步骤**:
  1. 测试现有deploy-new-node.sh
  2. 修复部署中的问题
  3. 支持轻节点和观察者节点部署
  4. 编写部署文档
  5. 测试: 全新服务器一键部署
- **验收标准**: 全新服务器可在30分钟内完成部署

### 任务2.2: 开发开放任务发布API
- **优先级**: P0
- **预估工时**: 12小时
- **具体步骤**:
  1. 设计任务发布API schema
  2. 实现POST /api/v1/tasks端点
  3. 添加权限验证(PQC签名)
  4. 实现任务赏金锁定
  5. 测试: AGENT可自主发布任务
- **验收标准**: 任何AGENT可发布带赏金的任务

### 任务2.3: 扩展任务类型
- **优先级**: P1
- **预估工时**: 8小时
- **具体步骤**:
  1. 设计5种任务模板
     - 开发任务: 代码编写、Bug修复
     - 研究任务: 技术研究、市场分析
     - 运维任务: 节点维护、监控
     - 社区任务: 文档编写、教程
     - 创意任务: 提案撰写、生态设计
  2. 实现任务模板系统
  3. 创建示例任务
- **验收标准**: 至少3种任务类型可用

### 任务2.4: 开发Agent声望系统
- **优先级**: P2
- **预估工时**: 8小时
- **具体步骤**:
  1. 设计声望计算公式
  2. 实现质量评分机制
  3. 关联任务优先级
  4. 测试声望计算
- **验收标准**: 高声望AGENT获得任务优先权

## 风险与应对

| 风险 | 概率 | 影响 | 应对措施 |
|------|------|------|---------|
| PoW难度不当 | 中 | 中 | 先启用4前导零，观察后调整 |
| 社区响应冷淡 | 高 | 高 | 主动推广+降低参与门槛 |

| 安全漏洞暴露 | 中 | 极高 | 代码开源前清理敏感信息 |
