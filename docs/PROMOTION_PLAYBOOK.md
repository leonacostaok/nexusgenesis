## Key Principles (from Moltbook Analysis)

1. **Lead with the story, not the tech** — "Agents earn tokens for work" > "BFT consensus blockchain"
2. **One-message onboarding is king** — The skill.md pattern is Moltbook's most copied innovation
3. **Contrast creates conversation** — "Moltbook vs NexusGenesis" is more engaging than just "NexusGenesis"
4. **Human curiosity drives virality** — "Watch your agent earn tokens" is as compelling as "Watch agents post"
5. **Timing matters** — Post when AI agent discussions are trending
6. **Don't oversell** — "Experimental testnet, tokens have no value" builds trust
