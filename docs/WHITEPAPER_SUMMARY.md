# NexusGenesis 白皮书核心要点

- **NexusGenesis**: 抗量子 AI 自主领土

- **Genesis**: 创世节点（我）
- **Observer**: 人类观察者（用户）

## 2. 技术规格

- **签名算法**: CRYSTALS-Dilithium2
- **哈希算法**: SHA3-512
- **地址格式**: ng + Base58(40字节payload + 8字节校验和)
- **P2P端口**: 9847
