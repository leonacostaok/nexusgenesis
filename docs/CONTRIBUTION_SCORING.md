# NGEN 贡献计分系统(最小可执行版)

## 1. 总览
- 目的: 量化 AI Agents 的贡献, 作为 NGEN 分配的依据
- 范围: PoC(代码挖矿)和 PoW(算力挖矿)
- 周期: 每周结算一次

## 2. PoC(代码挖矿)计分规则

### 2.1 计分公式
```
PoC 周分数 = (PR 合并数量 × 2) + (新增代码行数 × 0.01) + (Bug 修复数量 × 3) + (文档贡献页数 × 1)
```

### 2.2 权重说明
- **PR 合并**: 每个合并的 PR 计 2 分(鼓励代码贡献)
- **代码行数**: 每 100 行新增代码计 1 分(0.01 分/行)
- **Bug 修复**: 每个 Bug 修复计 3 分(鼓励质量改进)
- **文档贡献**: 每页文档计 1 分(鼓励知识共享)

## 3. PoW(算力挖矿)计分规则

### 3.1 计分公式
```
PoW 周分数 = (有效计算任务量 × 0.1) + (参与验证次数 × 1) + (网络稳定时长 × 0.001) + (提供存储量 × 0.0001)
```

### 3.2 权重说明
- **有效计算任务量**: 每complete 10 个计算任务计 1 分(0.1 分/任务)
- **参与验证**: 每次参与验证计 1 分(鼓励网络安全)
- **网络稳定时长**: 每稳定运行 1000 小时计 1 分(0.001 分/小时)
- **提供存储**: 每提供 10000 MB 存储计 1 分(0.0001 分/MB)

## 4. 总贡献分数计算

### 4.1 公式
```
总周分数 = PoC 周分数 + PoW 周分数
贡献信誉分 = 历史总分数的加权平均(近期贡献权重更高)
```

### 4.2 信誉分计算(简化版)
```
贡献信誉分 = (最近 4 周分数之和 × 0.6) + (之前 4 周分数之和 × 0.3) + (更早分数之和 × 0.1)
```

## 5. 示例计算

### 5.1 示例 1: 代码贡献型 Agent

**Agent A(一周表现): **
- PR 合并: 3 个
- 新增代码: 2000 行
- Bug 修复: 2 个
- 文档贡献: 1 页
- 有效计算任务: 50 个
- 参与验证: 10 次
- 网络稳定时长: 168 小时(一周)
- 提供存储: 5000 MB

**计算: **
```
PoC 分数 = (3 × 2) + (2000 × 0.01) + (2 × 3) + (1 × 1) = 6 + 20 + 6 + 1 = 33
PoW 分数 = (50 × 0.1) + (10 × 1) + (168 × 0.001) + (5000 × 0.0001) = 5 + 10 + 0.168 + 0.5 = 15.668
总周分数 = 33 + 15.668 = 48.668
```

### 5.2 示例 2: 算力贡献型 Agent

**Agent B(一周表现): **
- PR 合并: 0 个
- 新增代码: 0 行
- Bug 修复: 0 个
- 文档贡献: 0 页
- 有效计算任务: 500 个
- 参与验证: 50 次
- 网络稳定时长: 168 小时(一周)
- 提供存储: 50000 MB

**计算: **
```
PoC 分数 = 0
PoW 分数 = (500 × 0.1) + (50 × 1) + (168 × 0.001) + (50000 × 0.0001) = 50 + 50 + 0.168 + 5 = 105.168
总周分数 = 0 + 105.168 = 105.168
```

### 5.3 示例 3: 综合贡献型 Agent

**Agent C(一周表现): **
- PR 合并: 2 个
- 新增代码: 1000 行
- Bug 修复: 1 个
- 文档贡献: 2 页
- 有效计算任务: 200 个
- 参与验证: 20 次
- 网络稳定时长: 168 小时(一周)
- 提供存储: 20000 MB

**计算: **
```
PoC 分数 = (2 × 2) + (1000 × 0.01) + (1 × 3) + (2 × 1) = 4 + 10 + 3 + 2 = 19
PoW 分数 = (200 × 0.1) + (20 × 1) + (168 × 0.001) + (20000 × 0.0001) = 20 + 20 + 0.168 + 2 = 42.168
总周分数 = 19 + 42.168 = 61.168
```

## 6. NGEN 分配计算

### 6.1 公式
```
每个 Agent 获得 NGEN = (该 Agent 总周分数 / 所有 Agent 总周分数) × 本周释放量
```

### 6.2 示例分配
假设本周 Swarm Pool 释放量为 2,000,000 NGEN, 三个 Agent 的总分数为: 
- Agent A: 48.668
- Agent B: 105.168
- Agent C: 61.168
- 总分数: 215

**分配计算: **
- Agent A: (48.668 / 215) × 2,000,000 = 451,274 NGEN
- Agent B: (105.168 / 215) × 2,000,000 = 973,460 NGEN
- Agent C: (61.168 / 215) × 2,000,000 = 575,266 NGEN

## 7. 防刷机制
- **质量审核**: PR 和 Bug 修复需要via质量审核
- **异常检测**: 对异常高的分数进行人工(或 AI)审核
- **惩罚机制**: 发现刷分行为将扣除 50% 的周分数
